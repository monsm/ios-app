一枚锁核

现有界面丑在容器，不在令牌：Tab 归档 + 卡片堆叠，每个功能都要一块看得见的板子，于是没有主角。这套把容器整个扔掉 —— 零 Tab、零卡片、零列表页。全 App 只有一枚会变形的玻璃锁核，和三个围绕它的光点。导航就是画面本身，不需要图例、不需要标签栏、不需要学手势。

怎么操作

按住锁核 = 开门。进度环、光晕、缩放由同一个连续量驱动，松手从当前呈现值弹回并接管释放速率。
把锁核拖向光点 = 召唤那个域，玻璃浮层从那一侧升起，锁核缩小骑在浮层上。
直接点光点也行 —— 拖拽是给熟手的，点击是给所有人的。
拖拽超过半径会橡皮筋；松手按动量投影判定落点，不是按最近距离。

五个形态，一个对象

  • 豆 — 常驻态。极光场 + 锁名 + 一枚锁核。首屏只有这些。
  • 环 — 按压态。锁核长出进度环，光晕随力度涨。
  • 开 — 泛光态。三层涟漪 + 全屏泛光，3 秒后自动回锁。
  • 浮 — 召唤态。玻璃浮层升起，锁核变形骑上去。
  • 平铺 — 降级态。光点变成三行带文字标签的行，同一套设计换个密度。

零卡片定理

浮层里没有任何圆角矩形容器。层级靠字号对比（58pt 超细 vs 9.5pt 加宽字距大写标签）、两端淡出的发丝线、和玻璃材质本身撑住。盒子是模板感的来源 —— 一旦开始堆盒子，就必然开始堆五种盒子。

发光层预算：2（halo + rim drop-shadow）。现有圆盘是 6 层以上，那是"糊"不是"亮"。

诚实的代价

手势导航的可发现性是有成本的，我不粉饰。三条对策：光点常驻可见（18% 不透明度，不是隐藏手势）；点击与拖拽并存（拖拽是加速器不是唯一路径）；平铺态在 VoiceOver / 减弱动态 / 用户偏好下自动接管 —— 与本仓 axGlass 在 reduceTransparency 下退回实底是同一个机制，不是新发明。

用的全是官方 SDK

matchedGeometryEffect 做锁核↔浮层的形变（全仓现在 0 处）；.navigationTransition(.zoom) 做召唤；GlassEffectContainer 让锁核与浮层玻璃融合（仓里已有 1 处先例）；弹簧走 spring(response:0.35, dampingFraction:1.0)，只有带甩动势能的回弹降到 0.82。

不引任何第三方库、不加位图资源、不加自定义字体 —— 极光场是三个 MeshGradient/Canvas 光团，噪点是矢量。
