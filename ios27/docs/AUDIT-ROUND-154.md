## 3. 本轮的实际产出：把判据写进方法论

`AUDIT-METHOD.md` 新增 §1.9：

> `value <= 阈值 ? 警告 : 正常` 这个写法有一个系统性盲区：**占位值几乎总在阈值以下**。
>
> 修法不是"把阈值调大"，而是**把占位值从警告条件里排除**：
>
> ```swift
> // 错：-1 <= 20 ⇒ 警告
> tint: lock.battery <= 20 ? .warning : .normal
> // 对：两段判据
> tint: lock.battery >= 0 && lock.battery <= 20 ? .warning : .normal
> ```
>
> **为什么"恒定的假值"比"未知"更糟**：未知会让人去查，假值不会。
> 「-1 %」让用户困惑，「信号 0/4」让用户以为信号差 —— 两者都不会让人想到"其实没测过"。
