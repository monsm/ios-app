# V10 · Quiet Instrument（2026-11-06 全量视觉重做）

> 触发：用户要求「对现有界面整体做一次视觉样式重做，只改视觉，功能、交互流程与文案一字不动；
> 风格要现代、简洁、克制；所有页面共用一套设计变量」。
> 平台事实：本工程是 **SwiftUI 原生 iPhone 应用**（`TARGETED_DEVICE_FAMILY=1`，竖屏），
> 因此「1440 / 1024 / 768」这三个视口在本工程**不存在**；
> 宽度验收落在 **375（iPhone SE） / 390 / 430（Pro Max）+ Dynamic Type 档**。

---

| 组 | 内容 | 本轮变化 |
|---|---|---|
| `V8.C` | 颜色 | 去掉五套 Tab 大气色与页面辉光；纸面改单一冷灰；描边/分隔线统一为一档 |
| `V8.D` | 数据色 | 只编码「类别」（密码 / 指纹 / 临时码 / 手机钥匙），不编码「重要」 |
| `V8.T` | 字号（14 级） | 正文 17→15、脚注 15→13、页状态行 20→22；读数仍是 17 semibold |
| `V8.S` | 间距 | 全 4pt 节奏：42.4→24、22.1→36、18.6→16、10.6→10；新增表格首列宽 72/48 |
| `V8.R` | 圆角 | 卡片 14→16、凹槽 10→12，新增控件 10 / 弹窗 24 |
| `V8.E` | 描边 | 发丝 0.4；新增焦点环 2 |
| `V8.Z` | 阴影 | 全 App 一级抬升：10pt 环境 + 2pt 接触 |
| `V8.O` | 状态不透明度 | 禁用 0.45 / 按下 0.72 / 悬停 0.92（原来每页各写一个 0.45） |

**页面不再各自写样式**：`Gates/tokens.js` 判「0 处硬编码样式字面量」，本轮仍为 0。

## 三、宽度与溢出（375pt）

| 风险点 | 处理 |
|---|---|
| 锁设置页「容量三环」3×93.7+2×12 = 305pt（余量仅 6pt） | 环径改令牌 88 → 288pt，余量 23pt |
| 手机钥匙覆盖率环 / 安全页保护项环 / 动态码倒计时环（145 / 158pt） | 统一为 132pt，文字多留 20–35pt |
| 一排动作按钮（硬件页 / 网关行 / 批量延期 / 角色芯片 / 色标） | 走 `VButtonRow`，放不下自动竖排 |
| 固定 24×24 数字格与代号格（大字号裁字） | 改 `minWidth/minHeight` |

镜像台新增 `DesignLab/overflow-audit.js`：在指定宽度下渲染全部 54 屏并量 `scrollWidth`，
**375pt 与 430pt 均无横向溢出**。镜像台的令牌来源已从 V7 换成 V8
（此前镜像与真机是两套设计语言，截图"看着还行"、真机却是另一个样子）。

## 四、V7 的四个在用面全部迁走

`LockGateScreen`（冷启动闸）、`CaptureShield`（截图遮挡）、`FullPageCapture`（截图纸色）、
`SettingsModel`（动效档）—— 迁完后**在屏页面只引用 V8**。
V7 的令牌与组件文件仍在仓里，但已无在屏消费者（历史沉淀，删除与否是另一件事）。
