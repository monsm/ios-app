# 离线锁管家 iOS 27 · 设计契约（v1 · LOCKED）

> 这份文件是**唯一事实来源**。任何页面、任何组件、任何动效，先在这里找到依据；
> 找不到依据的写法就是错的写法。实施中遇到歧义 → 查 §11 裁决表，不许自行发明。

---

## 0. 一句话

**把门锁当成一台精密仪器来读，而不是把门画在屏幕上。**

上一版的隐喻是"一扇门"（门扇 / 门缝 / 锁体 / 推门而入）——那是**画**。
这一版是**读**：门锁有读数（电量、信号、凭证数、最后一次事件、固件版本），
界面就是这台仪器的面板：刻度、读数、游标、台账。

仪器面板的好处是**诚实的**：刻度必须量到真东西，读数必须来自真协议，
状态必须能一眼分辨。这正好是这个 App 的场景要的东西 —— 用户站在楼道里，
单手，可能很暗，开不了锁就要被关在门外。

## 1. 产品与场景（决定了所有取舍）

| 项 | 值 |
|---|---|
| 用户 | 家里装了这把离线锁的人，以及他家人 |
| 场景 | 站在自家门口、单手、可能昏暗、**失败 = 被关在门外** |
| 首要任务 | 3 秒内确认"能不能开"，然后开 |
| 次要任务 | 管凭证（密码/指纹/临时码）、查谁开过门、管家人的钥匙 |
| 频率 | 开锁：每天几十次（**不能有装饰动效**）；管凭证：每周几次；查记录：每月几次 |
| 技术边界 | 全离线、蓝牙直连、无账号云同步；协议层已存在且不许改 |

**推论**：
1. 状态必须**一眼可辨**（形状 + 颜色 + 文字三通道，不能只靠颜色）。
2. 高频动作零装饰；低频高情绪动作（开锁成功）才允许一次克制的动效。
3. 一切"好看"的装饰若不能承载信息，删。

## 2. 设计立场（这一段是审美的依据，不是形容词）

### 2.1 参照系：计量仪器，不是门

真实的仪器面板长什么样：**蚀刻刻度、单一游标、定宽读数、单位小字、极细分割线**。
它没有渐变光斑、没有玻璃卡片堆、没有三个图标卡片并排。

本 App 借三样东西：

| 借来的 | 怎么用 | 不许怎么用 |
|---|---|---|
| **刻度尺（Scale）** | 只在**真的有量**的地方画：信号强度、电量、时间轴、进度 | 当装饰花纹铺在每张卡上 |
| **定宽读数（Reading）** | 所有数字右对齐 + 等宽数字 + 单位小字 | 把数字当大字报堆在标题里 |
| **游标（Cursor）** | 当前状态在刻度上的位置（唯一一处强调色） | 同屏出现两个游标 |

### 2.2 三条反模板纪律（对照 anti-slop 的三张"默认脸"）

1. **不要暖奶油 + 衬线 + 陶土色**：上一版就是暖金 + 门，这一版底色是**冷石墨 / 冷纸**，不是奶油。
2. **不要近黑 + 一个荧光强调色**：强调色不是荧光绿/朱红，是**铜锈绿（patina）**——
   铜锁氧化后的颜色，来自产品自己的材料，不是调色盘上的流行色。
3. **不要细线大报排版**：刻度线只出现在有量的地方，不是每行下面都拉一条。

### 2.3 唯一能被记住的东西（signature）

**那枚刻度盘（The Dial）**：
一圈 0.5pt 蚀刻刻度（60 格，每 5 格一根长刻度），一段**真实进度弧**（不是装饰），
中心是定宽读数（状态词），下面是单位小字（上次动作距今 / 电量 / 信号）。
按下 = 开锁，弧从 0 走到 1 —— **走的是真命令链**（查钥匙 → 连 BLE → cmd04 → 回执），
不是假动画。失败时弧停在断开的位置并变朱红，不假装成功。

## 3. 颜色（唯一来源：`Tokens.swift` 的 `Ink` / `Signal` / `State`）

**色相预算：全 App 只有两个色相族 —— 石墨（无彩）与铜锈（唯一品牌色）。**
状态色（注意/危险）是**语义色**，不是品牌色，只在真实状态出现。

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `paper` | #F2F2EF | #0B0C0D | 页面底（冷纸 / 冷石墨，**不是奶油、不是纯黑**） |
| `plate` | #FFFFFF | #15171A | 卡片 / 面板 |
| `plateAlt` | #E9E9E4 | #1D2024 | 凹槽 / 内嵌块 / 刻度底 |
| `hairline` | #C9C9C2 | #2E3237 | 分割线（≥1.25:1 才看得见） |
| `ink` | #14161A | #F3F4F2 | 主文本 |
| `inkSub` | #5B6169 | #A2A9B2 | 次文本 |
| `inkFaint` | #8A9098 | #6E757E | 单位小字 / 刻度标注（仅 ≥12pt 且非关键信息） |
| `signal`（品牌/铜锈） | #1D6F5F | #47C9A6 | 主行动填充、选中态、**live** 游标 |
| `onSignal` | #FFFFFF | #06201A | 压填充上的文字（深色用近黑墨，不用白） |
| `attention` | #8A5A0B | #E2A63A | 注意（低电、待同步、待下发） |
| `critical` | #A32B22 | #FF6A5C | 危险（开锁失败、越界、已失效） |

**规则**
- 同屏 `signal` 只出现在**一处主动作**。其余控件一律墨色。
- `attention`/`critical` 只随真实状态出现，**不许当装饰**。
- 深色模式不是浅色的反相：两套独立取值，深色底**不是纯黑**（#0B0C0D，留一点抬升空间给 plate）。
- 所有前景/背景组合必须过 `Gates/contrast.js`（WCAG：≤17pt 要 4.5:1，≥18pt 或粗体要 3:1）。

## 4. 字体与读数

| 角色 | 规格 | 备注 |
|---|---|---|
| 显示标题 | `.system(size: 34, weight: .semibold, design: .default)` + `tracking(-0.4)` | 中文标题**最高 semibold**：苹方无 Bold，`.bold()` 会静默回退 |
| 页面小节标题 | `.system(size: 13, weight: .semibold)` + 全大写拉丁才加 tracking | 中文不加 tracking（方块字等宽） |
| 正文 | `.system(size: 15)` / `.body` | 中文正文下限 12pt，不用 caption2 |
| **读数** | `.system(size: N, weight: .medium, design: .monospaced)` + `.monospacedDigit()` | 一切数字走这个；等宽保证换值不跳宽 |
| 单位小字 | `.system(size: 11, weight: .regular)` + `inkFaint` + 字距 +0.6 | 只在读数旁，从不单独成句 |

**读数规则（这是本设计的性格）**
- 数字**右对齐**（`.frame(maxWidth: .infinity, alignment: .trailing)`），单位紧随其后。
- 时间一律 `HH:mm`（等宽），日期一律 `MM-DD`；跨年才显示年。
- 计数不写"共 N 条"，写成 `N` + 单位小字 `条`。

## 6. 材质（Liquid Glass 的纪律）

iOS 27 的玻璃是**功能层**的材质，不是内容层的装饰。本 App 的用法：

| 层 | 材质 | 出现处 |
|---|---|---|
| 功能层（浮动控件） | 系统原生玻璃（`.glassEffect` / `.buttonStyle(.glass)`） | Tab bar、导航栏按钮、浮动操作条、sheet 顶栏 |
| 内容层 | **不透明** `plate` / `plateAlt` | 卡片、列表、读数块、刻度盘底 |

**硬规则**
1. 内容层**永不用** `glassEffect`。玻璃出现在卡片上 = 缺陷。
2. 同屏自定义玻璃面 **≤2**，且**不叠玻璃**。
3. 玻璃上只放**单色**符号/文字；颜色留给主动作。
4. 减少透明度 / 提高对比度 开启时 → 玻璃退化为不透明 `plate` + 描边（用 `@Environment(\\.accessibilityReduceTransparency)` / `IncreaseContrast`）。
5. 滚动边缘用 `.scrollEdgeEffectStyle(.soft, for: .top)`，**不许**自己铺一条半透明底。

## 7. 动效（仪表动效，不是玩具动效）

**Motion 人格：Premium（精密、克制、无回弹）**

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `snap` | `.spring(response: 0.22, dampingFraction: 0.92)` | 按压、切换、chip 选中 |
| `move` | `.spring(response: 0.32, dampingFraction: 0.88)` | 卡片进出、行展开 |
| `sweep` | `.timingCurve(0.32, 0, 0.16, 1, duration: 0.6)` | **只给刻度盘进度弧**（真实进度必须线性可信，不能用弹簧过冲骗人） |
| `exit` | `.easeOut(duration: 0.18)` | 消失（比出现快 30~50%） |
| 数字换值 | `.contentTransition(.numericText(value:))` + `snap` | 所有读数 |
| 刻度点亮 | 逐格 `delay(i * 0.008)`，最多 60 格 = 480ms 上限 | 只在开锁链推进时 |

**纪律**
- 只动 `transform` / `opacity` / `foregroundStyle`；**不动** frame/padding/布局。
- 高频交互（滚动、切页、刷新）**零装饰动效**。
- 无限循环动画必须独立成视图 + `.transaction { $0.animation = nil }` 切断继承（否则与外层 `animation(_, value:)` 抢属性）。
- `reduceMotion` 开启时：进度弧**保留**（它是信息），但取消逐格点亮与数字滚动，改为直接跳变。
- 触觉：只在**结果态**（开锁成功/失败/警告）用 `.sensoryFeedback`；按压与切换不铺触觉。

## 8. 导航与信息架构

```
RootView
 ├─ LockGate（本机密码闸；冷启动才要求）
 └─ Shell
     ├─ Tab 1 「门」   DoorView      —— 刻度盘 + 读数 + 最近一条事件
     ├─ Tab 2 「钥匙」  KeysView      —— 凭证台账（密码/指纹/临时码）+ 月历
     ├─ Tab 3 「台账」  RecordsView   —— 时间轴台账 + 检索 + 筛选 + 导出
     ├─ Tab 4 「家」    HouseholdView —— 成员 / 角色 / 归档 / 家庭设置
     └─ Tab 5 「设置」  SettingsView  —— 门锁节 / 安全 / 外观 / 备份 / 关于
     + Tab(role: .search)            —— 系统搜索 Tab（全局检索，morph 成搜索框）
```

**规则**
1. 5 个 Tab + 1 个 search Tab。Tab 只**导航**，不**执行**（开锁只在「门」页的刻度盘上）。
2. 子页一律 `NavigationStack` + `navigationTitle`；最深 2 层。
3. 跨 Tab 跳转走**唯一漏斗** `Router.request(_:context:)`（`App/Shell/Router.swift`），
   带上下文，不裸切 Tab。
4. 模态：`.sheet` 一次只一个；必须有出口（取消 / 关闭 / 下滑）。
5. 每个 Tab 根用 `.tabBarMinimizeBehavior(.onScrollDown)`，让内容顶到玻璃下面。

## 10. 验收（机器可验证 + 肉眼可验证）

**机器闸门**（`Gates/`，CI 与本地都跑）
| 闸门 | 判什么 |
|---|---|
| `swiftcheck.js` | 括号/字符串平衡（无本地 Swift 编译器时的第一道闸） |
| `tokens.js` | 页面里不许出现硬编码颜色/间距/圆角/字号（必须走 `T.`） |
| `contrast.js` | 从 `Tokens.swift` 解析色值，逐条核算 WCAG |
| `glass.js` | 内容层不许出现 `glassEffect`；同屏玻璃面 ≤2 |
| `motion.js` | 不许出现无 `value:` 的 `.animation`；无限循环必须独立视图 |
| `a11y.js` | 图标按钮必有 label；触达 <44 判失败；裸 `.font` 判失败 |
| `destmap.js` | 目的地台账与 View 对账（少一个页面没人发现） |

**肉眼闸门**（DesignLab 截图）
- 每屏必须在 `DesignLab/` 有 1:1 镜像，用同一套 token 生成，Edge headless 截图。
- 每屏至少验：浅色 / 深色 / 空态 / 加载态 / 错误态（有的话）。
- 判据：**同屏只有一个主角**；刻度都量到真东西；读数右对齐等宽；无模板脸。

## 11. 歧义裁决表（实施时最常撞上的）

| 疑问 | 裁决 |
|---|---|
| 要不要保留上一版的"一扇门"门面层？ | **不要**。那是画，不是读。全部推倒。 |
| 要不要沿用上一版的暖金色？ | **不要**。那是陶土色族，模板脸。用铜锈绿。 |
| 数字能不能用大字号当标题？ | **不能**。读数是读数，标题是标题。 |
| 能不能给卡片加玻璃？ | **不能**。内容层不透明。 |
| 刻度能不能当装饰？ | **不能**。量不到东西就不画。 |
| 开锁能不能做成很炫的动画？ | **不能**。弧走真进度，失败就停在断点。 |
| 空态能不能只写"暂无"？ | **不能**。空态必须给下一步出路。 |
| 能不能用 `01/02/03` 编号？ | **只在真序列**（配网四步、建档向导、开锁链）用。 |
| 深色模式能不能把浅色反相？ | **不能**。两套独立取值。 |
| 中文标题能不能 `.bold()`？ | **不能**。苹方无 Bold，静默回退 semibold。 |
| 能不能新增第 6 个 Tab？ | **不能**。溢出进「设置」或 App Index。 |
| 上一版那 28 个 Destination 怎么办？ | 按功能重排进 5 个 Tab 的子页；**功能点不丢**，入口可合并。 |
