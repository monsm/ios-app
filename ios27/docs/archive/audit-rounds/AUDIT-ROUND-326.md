# AUDIT-ROUND-326 · 第 326 轮：把「页面外壳」交还给系统，而不是自己画

> 接第 325 轮（整页回退）。本轮做的是**把属于系统的部分交回去** —— 标题、搜索、顶边处理。
> 先说明一个前提：**DesignLab 的截图不能作为验收依据**，理由见 §5。

## 1. 一个必须先纠正的事实：门页从来没有标题

`DoorScreen` 的 `body` 里：

```swift
.toolbarVisibility(.hidden, for: .navigationBar)
```

导航栏被整个关掉，而页内也**没有任何一处**画「前门 / 锁名」这样的标题
（`chips` 只是「概览 / 电量 / 版面」三个功能芯片，不是标题）。

⇒ 用户打开 App 的第一屏，**看不出自己在控制哪把锁**。

而 DesignLab 的 `door.dark.png` 里赫然有个 34pt 的「前门」—— 那是**镜像自己画的**，
SwiftUI 里从来不存在。这正是「看图验收」失效的直接证据。

## 2. 本轮四处改动

| 改动 | 位置 | 为什么 |
|---|---|---|
| 系统大标题承载锁名 | `DoorScreen` | 补上缺失的页面标题；大标题随滚动收成 inline，导航栏这时才出现**液态玻璃** |
| 可见的开锁提示 | `DoorScreen.gaugeBlock` | 圆盘是主控件，中心却只写电量；「轻点开锁 / 按住 0.9 秒」**只存在于 `accessibilityHint`**，看得见屏幕的人反而看不到 |
| 顶边统一 `.soft` | 17 个页面 | 原本 17 页有、18 页没有 ⇒ 一半页面内容在状态栏下**柔和淡出**、另一半**硬切** |
| 系统大标题 + 系统搜索 | `SettingsScreen` | 自绘 TextField + 自绘放大镜 + 自绘清除按钮，都拿不到系统搜索栏的材质/取消按钮/键盘处理 |

## 3. 为什么「换原生控件」这次对了，上次错了

| | 第 324 轮（错） | 本轮（对） |
|---|---|---|
| 换的是什么 | **内容层**的卡片容器（`VCard` → `GroupBox`） | **功能层**的页面外壳（标题 / 搜索 / 顶边） |
| 得到什么 | 一个**不透明**的系统卡片，零玻璃 | 导航栏玻璃、搜索栏玻璃、系统折叠与滚动手势 |
| 代价 | 整套 gutter/间距被压平（第 325 轮量化过） | 只改页面顶部，卡片与间距不动 |

判据：**HIG 说玻璃只在功能层。所以「换原生」必须换在功能层 —— 换内容层既没玻璃又毁布局。**

## 4. HIG 机检结果（首次接入 `hig_audit`）

```
critical 0 · serious 0 · moderate 54 · positives 347
```

54 条 moderate 里绝大多数是**误报**（把 `@State var` 声明本身标成"状态管理问题"）。
真实信号只有一类：`.background(V.C.bg.ignoresSafeArea())` ×20 ——
而「背景铺满到屏幕边缘」恰恰是 HIG 要求的做法，不是缺陷。

结论：**机检只能当"没有硬伤"的底噪，不能当设计判据。** 真正的问题（门页没标题）它没报。

## 5. DesignLab 的定位必须改：它是**设计稿**，不是**实现快照**

| 事实 | 后果 |
|---|---|
| `screens.js` 是手写数据，不是从 SwiftUI 生成 | 它画的是**意图**，不是**现状** |
| 它自绘了一条假标签栏 | 真机是系统 `TabView`（全宽 + 收起行为），两者完全不同 |
| 它给门页画了「前门」标题 | SwiiftUI 从来没有这个标题 |
| 它给门页画的圆盘中心是「就绪」 | SwiftUI 中心是**电量数字 + "电量"** |

⇒ 本轮起，**DesignLab 截图只用于"设计意图"参考，不再用于验收实现**。
验收改用：①云端编译 ②23 道静态闸门（含真 `swift-parser`）③HIG 机检 ④代码级读数核对。

## 6. 方法论

| 判据 | 出处 |
|---|---|
| **页面标题属于功能层** —— 用 `.navigationTitle`，不要自己画；自绘拿不到折叠、玻璃、无障碍语义 | 本轮 §2 |
| **主控件的操作提示必须可见** —— 只写进 `accessibilityHint` 等于对多数用户不存在 | 本轮 §2 |
| **同一种视觉处理要么全有要么全无** —— 17 有 18 无的"顶边淡出"比统一没有更糟 | 本轮 §2 |
| **「设计稿」与「实现快照」是两种东西**，混用会让"看图验收"变成自我确认 | 本轮 §5 |
| **机检通过 ≠ 设计没问题** —— 54 条误报里没有一条提到"门页没有标题" | 本轮 §4 |
