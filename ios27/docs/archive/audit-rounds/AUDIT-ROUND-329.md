# AUDIT-ROUND-329 · 第 329 轮：大字号下会裁字的头像，以及一次设计系统一致性核对

## 1. 修掉两处「固定容器装缩放文字」

头像是**固定直径的圆**，里面是**随 Dynamic Type 缩放的文字**：

| 位置 | 改前 | 改后 |
|---|---|---|
| `HHAvatar`（成员头像，3 处调用） | `frame(width: size, height: size)` | 直径 × `@ScaledMetric(relativeTo: .body)` |
| `RecordsScreen` 页头「我」头像 | `frame(width: 34, height: 34)` | 同上 |

默认字号下因子 = 1，**观感零变化**；系统字号调到辅助功能档时，圆跟着字一起长，字不再被裁掉。

判据（HIG · Layout / Typography）：**容器要容纳内容，不是把内容裁进容器。**

## 2. 设计系统一致性核对（本轮扫描结论）

顺带做了一次全仓核对，结论是**这几处本来就是齐的**，不需要改：

| 检查项 | 结果 |
|---|---|
| 硬编码圆角 | 1 处（`RoundedRectangle(cornerRadius: 1.2)` 一个小圆点，合理） |
| 硬编码线宽 | 0 处 —— 全部走 `V.S.hair` |
| 卡片标题组件 | `VCardHeader` 60 次 / `VSectionLabel` 117 次，**没有任何一个页面混用两者** |
| 固定高度 `.frame(height:)` | 0 处 |
| 占位/TODO 文案 | 0 处（47 条命中全是表单 placeholder 的正常提示） |

⇒ **这套设计系统本身是干净的。** 之前几轮"丑"的来源不是系统乱，是**容器被换掉**（第 324 轮）与**标题画两遍**（第 325/328 轮）。

## 3. 方法论

| 判据 | 出处 |
|---|---|
| **固定尺寸容器 + 缩放字体 = 一定会裁字**，只是默认字号下看不出来 | 本轮 §1 |
