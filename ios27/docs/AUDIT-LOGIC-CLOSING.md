## 6. 剩下的必须上真机（不是"还没做"）

| 项 | 为什么这里做不了 |
|---|---|
| 开锁是否真的成功（rc=0） | 需要真锁与蓝牙；本机只能验证**命令帧结构**与**错误码路径** |
| 校时后偏差是否个位数秒 | 逻辑已修，需真锁回读确认 |
| 交互流水里能否看到 rc | 需复现一次真实失败 |
| 指纹录入 8 次、DFU 实刷、BLE 回执 | 全部需要真机 |
| 观感（12/24 制式、玻璃、字号） | 需要真机或模拟器 |

**这 5 项的共同点：不是"没做完"，而是"这台机器上做不到"。**
继续加轮次不会让它们前进一步 —— 只会产生"为了有产出而硬改"的风险。
