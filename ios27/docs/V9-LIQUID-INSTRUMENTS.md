# V9 · 液态仪器（2026-11-06 设计质变记录）

> 触发：用户反馈「现在 iOS27 App 设计太素！我要丰富多样的液态玻璃原生质感！
> 每个页面每个控件都重新设计，做最深层次的质变」。
> 基线：ed24dcd7 之前（B− 评级 · 41 道闸门全绿 · 全平色卡片 + 零投影 + 单蓝强调）。

## 一、设计判断

「素」的根源不在布局（判断句 + 仪表盘语言成立），而在**材质层为零**：
卡片是纯白矩形、阴影 = 0、页面背景是单色平涂、玻璃只在 Tab 栏与滑块。
真实仪器面板有三种「厚度」：受光的面板（渐变）、嵌进去的凹槽（读数窗）、
凸起的玻璃控件（按钮/把手）。V8 把三者全画平了 —— V9 把它们全部还给界面。

## 二、三层材质体系（全部落在令牌与组件层，25+ 页自动继承）

### 内容层（HIG Materials：丰富靠色彩与光照）
| 新令牌 | 值（light / dark） | 消费点 |
|---|---|---|
| `bgTop / bgBottom` | #F7F6FB→#ECEBF3 / #0A0A0C→#000 | VPage 纵向天光 |
| `glowA / glowB` | 品牌蓝 10%/16% · 冷紫 8%/13% | VPage 顶部/尾部环境辉光 |
| `cardTop / cardBottom` | #FFFFFF→#F7F6FA / #232326→#17171A | VCard2 面板渐变 |
| `cardSheen` | 白 90%/10% | 卡片/表盘/胶囊顶缘受光高光 |
| 五套 Tab 大气色 | glowViolet/Indigo/Green/Graphite… | V8Atmosphere（门蓝/钥匙紫/台账靛/家绿/设置石墨） |

### 材质组件（一次改写，64 处卡片 / 65 处芯片 / 62 处导航行全继承）
- **VCard2**：渐变面板 + 顶缘 1pt 高光 + 双层投影（12pt 环境 + 3pt 接触）
- **VChip2**：选中 = 品牌色渐变凸台 + 高光环；未选 = 微凸面 + 发丝描边
- **VNavRow 图标砖**：顶部 18% 白光照渐变 + 高光描边（原生设置语法）
- **VStatPair2**：读数落进「凹槽读数窗」（well 底 + 暗缘，与玻璃凸台凹凸对偶）
- **VAvatar**：受光玻璃珠（顶 26% 光照 + 35% 品牌描边）
- **VHeroRing**：玻璃表盘 + 凹槽轨道（内阴影）+ 五段角向渐变填充
- **VSegmentedRing2 / VSpark / VEmpty 主按钮 / VFailure 警示条**：同一光照语法

### 功能层（玻璃仍是唯一入口，纪律不变）
- **GlassSurface**：原生玻璃 + 顶缘镜面渐隐高光（厚度感，不改折射）
- **GlassSlideToUnlock**：把手改为受光渐变玻璃钮（来电 UI 光照）
- **GlassTabBar**：选中胶囊 = 受光玻璃凸台 + cardSheen 高光
