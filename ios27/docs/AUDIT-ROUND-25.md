## 2. 修法

- 标题改成「二十道机器闸门（本地可跑，CI 同款）」；
- 代码块换成**实跑输出**；
- **在块前加一段显式声明**：这是某一时刻的快照，数字会变，
  **以 `node Gates/allgates.js` 的实际输出为准**，不要把这里当当前值引用 ——
  与其假装"写对了就永远对"，不如把"它会过期"写进文档本身；

|---|---|---|
| -2 | README | 「文档数字这块闭环了」 |
