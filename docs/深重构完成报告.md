## 四、拆分踩过的 9 类编译错误（全部已修）

1. **`private` 跨文件不可见** —— 6 种写法都要提升：`private var` / `private let` / `private func` / `private static` / `@State private var` / `@ObservedObject private var` / `@Environment(\.x) private var`
2. **`private(set)` 跨文件不可写** —— `@Published private(set) var` 需去掉 `private(set)`
3. **`@State` 不能放 extension**（Swift 不允许 extension 有存储属性）—— 必须留在主 struct
4. **`@ViewBuilder` 缺失 / 孤立 / 重复** —— 8 个 Section 属性 + 5 个渲染块补上；3 处孤立删除
5. **`@ToolbarContentBuilder`** —— `some ToolbarContent` 的多个 `ToolbarItem` 需要它
6. **extension 宿主写错** —— `extension RecordsRows`（`RecordsRows` 是 extension 不是类型）→ `extension RecordsView`
7. **嵌套类型跨文件不可见** —— `RowVM` / `DayGroup` / `Merged` 需 internal
8. **`@discardableResult` 孤儿** —— 方法搬走后属性留在原处
9. **`@preconcurrency import CoreBluetooth` / `import UIKit` / `import UserNotifications`** —— 拆出文件丢了 `@preconcurrency` 或整个 import
