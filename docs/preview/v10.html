Keeper · 第三版 · 高调光

一扇门，一张产品照。

上一版把 76 项塞进一个抽屉：门是道具，抽屉才是界面，两个世界。这一版把镜头推近到只剩门面——整屏是对开的两扇门，中缝上压着一枚嵌进材料的圆形锁体。轻点锁体：中缝先透出一线暖光，两扇门向两侧转出去，门后就是这个 App。进门之后没有门的隐喻，只有大标题、一个主操作和底部一颗液态玻璃 Tab。

为什么上一版丑

因为它是示意而不是产品照：一扇完整但平坦的白门，中央一块正方形，没有光的方向、没有倒角、没有景深。Apple 的界面很少把物体画成简笔画，它给物体打光。

这一版的四个决定

1 关着的时候，整屏就是对开的两扇门。 中缝一道，锁体正压在中缝上——它不是贴在门上的一块方屏，是这扇门的锁。左边一条门框，右边没有按钮，没有任何导航。

2 锁开了，中缝先透光。 一线暖光从两扇门之间漏出来，接着两扇门向两侧转出去，门自己消失——不是滑走、不是淡出，是转到与视线平行，背面被裁掉。

3 门后是常规 iOS。 大标题、状态胶囊、一个蓝色主操作、底部一颗液态玻璃 Tab（门 / 设备 / 记录 / 全部）。进门以后不再演任何隐喻，全部 76 项老老实实做成一页。

4 关门只要一个动作。 关着的时候，屏幕上能按的东西只有锁体；开着的时候，往回推一下就回到门外。

光的做法

高光不是装饰：右上角斜切下来的一道 sheen 说明光源在窗外；两扇门的中缝，左扇的边缘吃暗、右扇的边缘吃亮，一条缝因此有了厚度；圆盘外圈是铣进材料的金属倒角（conic 渐变，所以亮的地方随角度变），内层是深色玻璃，一道斜向高光说明它是玻璃；盘下 26px 的柔和投影说明它是嵌进去的，不是贴上去的。

锁体里的字形不是纯白贴纸——它是从上到下由白转灰的一块料，外加一层极淡的辉光，读起来像被上方的光打到。开锁时它由闭环换成开启，同时中缝亮起。高光还会跟着指针移动几像素：物体在光里，不是贴图。

为什么门要开

抽屉这套东西（遮罩、抓手、弹簧拖拽、投影）本来就是"浮在别的东西上面"的语言。既然整屏是一扇门，那它后面的东西不该是浮起来的，应该是走进去。所以抽屉、遮罩、抓手、甩动全部删掉：门就是入口，App 就是门后的房间。

还没做

开锁仍是模拟态；未接 Dynamic Type；只做了浅色；门后的四个 Tab 只有一级页面；门的 3D 用的是 CSS perspective，真机原生版要换成 Core Animation 的 CATransform3D。
