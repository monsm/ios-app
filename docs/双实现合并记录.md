## 改动明细

### 1. `FpStudio` 加 `embedded` 参数

它原来**总是**自带 `NavigationStack`：

```swift
var body: some View {
    NavigationStack {
        if step == 3 { doneCard } ...
    }
    .navigationTitle("录入指纹")
    ...
}
```

直接放进 `NavigationLink` 会「导航栏叠导航栏」。改成与 `PwdStudio` 同口径：

```swift
var body: some View {
    Group {
        if embedded { core } else { NavigationStack { core } }
    }
    .navigationTitle("录入指纹")
    .toolbar { ... }
    .onAppear { consumePendingOwner(); consumePrefill() }
    .onDisappear { enrollTask?.cancel() }
}

@ViewBuilder
private var core: some View {
    if step == 3 { doneCard }
    else if step == 1 { immersive }
    else { ScrollView { ... } }
}
```

## 附带修复

`rescuescan` 报 `existing` 悬空引用 —— 核实为**局部变量同名误报**：
工具的正则把 `if let existing = ...` 里的 `existing` 当成了定义名，
而删掉的结构体里也有一个同名局部变量。

把我这处改名 `dupLock`（语义也更清楚：这是检测到重复的锁）。
