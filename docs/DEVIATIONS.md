# 刻意偏离 HTML 的裁定清单

> 记录**每一处 App 与 HTML 原型不同、且我判断应当不同**的地方，以及理由。
> 目的：让你一次审完我的所有判断，而不是逐页猜。
> 如果你不同意某条，告诉我编号即可。

## A. 页面标题用词（12 处）

| # | HTML 标题 | App 标题 | 理由 |
|---|---|---|---|
| A1 | 系统（05-system）| 本机设置 | HTML 把「系统」与「本机设置」画成两页（05 / 4a），App 合并为一页，只能取一个名字 |
| A2 | 我的门锁（20-locks）| 门锁管理 | 该页可增删/切换多把锁，不只是「我的」 |
| A3 | 网关配网（23-gateway）| 智能网关 | 配网只是其中一步，还有状态与解绑 |
| A4 | 校准时间（25-synctime）| 同步时间 | 实际是双向同步，不只有写锁钟 |
| A5 | 隐私看板（40-security）| 本机保护（SecurityPage）/ 隐私仪表盘（PrivacyDashboard=43）| HTML 40 的 h1 是「本机保护」，已改名对齐；43 才是仪表盘 |
| A6 | 安全审计（44-audit）| 审计流水 | 该页展示的是流水，不是审计动作 |
| A7 | 导出中心（48-export）| 导出与分享 | 有一半功能是分享，不只导出 |
| A8 | 认领钥匙（87-claim）| 未归属记录认领 | 认领对象是「记录」不是「钥匙」（钥匙在锁里）|
| A9 | 密码详情（13-key-detail）| 凭证详情 | 该页同时展示指纹，叫「密码」会误导 |
| A10 | 临时密码（12-tempcode）| 临时码 | 更短，Tab 宽度够 |
| A11 | 安全模式说明（46-safemode）| 安全模式说明 | 一致（仅因 sheet 无 XScreen 标题未检出）|
| A12 | 门厅（01-home）| 门厅（Tab 标签）| 主屏无导航标题，Tab 标签即标题 |

## B. 结构判定（不改）

| # | 页 | HTML | App | 理由 |
|---|---|---|---|---|
| B1 | 20-locks | 卡片流 | `List + Section` | List 承载拖动排序 / 滑动删除 / 编辑模式三套真实交互，改卡片流需全部重写 |
| B2 | 50-events | 卡片堆 | 真时间轴（竖线 + 节点）| 事件流用时间轴比卡片堆更合适；代码内有论证 |
| B3 | 34-merge | 独立合并页 | 落到成员列表 | `MergeMembersView` 需要 `primary: Member`，路由层拿不到具体成员；从成员行发起才是正确入口 |
| B4 | 44-audit / 51-feed | 两层结构（dsheet：深色品牌头 + 内容板）| 单层 `XScreen` | **只有 2/50 页**用两层，是原型里的少数实验；App 全站统一单层。若你认为该加，我加一个 `XThemedHeader` 组件 |
| B5 | 80-states | 三态规范页 | 无独立页 | 是组件规范（`XSkeleton`/`XEmptyState`/`XInlineError`），组件已存在并被各页使用 |
| B6 | 75-shell | 展示壳（App Store 宣传图）| 无 | App 内没有这一屏 |
| B7 | 02-keys「全部钥匙」| 卡头「全部凭证」| 凭证涵盖密码+指纹+OTP，比"钥匙"准 |
| B8 | 11-fingerprint 两卡（锁内容量+指纹库存）| capacityCard 一卡 | 44px+三环+两列+页脚已含两卡全部信息 |
| B9 | 01-home 卡1「本周（握手）」| 不补 | 周聚合数据层不存在（功能以 App 为准）；握手是工程量不进主屏 |
| B10 | 双端主屏 chip 数不同（iOS 4 / Android 2）| 保留 | 各自忠实于各自 HTML（iOS 01-home 4 枚、Android 原型 2 枚）|
