## 一、根本原因（这轮才查清）

真机 34 个界面里，**28 个有 HTML 原型可对照，6 个没有**。

| 无原型的 6 页 | 我上一轮做了什么 |
|---|---|
| 本机保护 | 把环从 76 放大到 150pt ← **凭感觉改，没有标准** |
| 这台锁 | 未动 |
| 连接与预握手 | 未动 |
| 距离标定 | 未动 |
| 事件 | 未动 |
| 还没有动态 | 未动 |

**这就是审美差距的机制：有 HTML 的页我照着做（门厅、钥匙、成员都很像）；
没 HTML 的页我凭感觉做（本机保护、这台锁就散掉了）。**
