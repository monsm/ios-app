## 四、方法论教训

1. **逐页必须以 HTML 源码为准**，不能凭印象（曾误以为 60-care 有横滑画廊，实测 `overflow-x` 零命中）
2. **`String.replace` 静默失败**——锚点不匹配时不报错，改完必须 `includes` 验证
3. **写读取代码前先 grep struct 定义**——`CachedLog.at` / `KeyRow.mac` / `iconOptions` 都是猜错的
4. **结构性插入后必查边界**——孤立 `private`、孤立字符 `s`、注释与修饰符同行，只有编译器能抓
5. **闸门全部有用**：`uicoverage`（自绘容器预算）、`swiftlint`（写死纯白）、`glassaudit`（AX 固定高度/跨文件同名）、`subtitlesync`（副标题基线）、`destmap`（呈现通道台账）—— 每一个都实际拦下过错误
