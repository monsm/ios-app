## 一、为什么审美差这么多（一句话）

**门厅是全 App 唯一照参考图结构做的页面，其余 27 页全是「设置清单」式排版。**

对比同一台手机的三个界面：

| | 门厅（图 596-598）| 本机保护（图 542）| 参考图 2 |
|---|---|---|---|
| 标题 | **1 个**（页内大标题）| **2 个**（导航栏+页内）| **1 个** |
| 顶部 | 4 枚胶囊横向滚动 | 无 | 4 枚胶囊横向滚动 |
| 主视觉 | 巨型开锁环（占屏 1/3）| 无 | 巨型健康环（占屏 1/3）|
| 卡片 | 少而精（2 张）| 多而密（4 张）| 少而精（3 张）|
| 彩色环 | 有（青/紫渐变）| 细灰环 | 有（红/绿/青 三色）|
| 留白 | 大 | 小 | 大 |

**结论：门厅是对的，其余页面没有照着做。**

## 三、四类具体审美缺陷（每类都有实例）

### 缺陷 1：卡片里塞工程参数（最伤审美）

实例：备份与恢复页的「加密参数」卡 —— 算法 AES-128 / 认证 HMAC-SHA256 / 派生 PBKDF2 6万轮。
参考图 2 的睡眠卡只有 5 项：Low Score / Duration 3h25m / Bedtime 10:30PM / Avg 2:19AM / 一句说明。

**改法**：工程参数收进「明细」二级页，主卡只留 1 个主数字 + 1 行说明 + 1 个彩色环。

### 缺陷 2：卡片是纯色，不是玻璃

实测：参考图卡内 R36 G37 B42（带蓝调，能透出背景），实机卡内 R29 G29 B31（中性灰，遮挡背景）。
**已修**：改为半透明白叠加（毛玻璃被 §14-#6 挡住，只能这样模拟）。

### 缺陷 3：彩色环太小/太灰

参考图的环占卡片右侧 1/3，饱和色（红 #FF3B30 / 绿 #30D158 / 青 #64D2FF）。
实机多数页面是**细灰环 + 一个小蓝点**（如备份时效、指纹余量、钥匙分布）。

### 缺陷 4：文字层级平（无大数字）

参考图每张卡都有 **44-56pt 的大数字**（665/750 CAL、13,818、6.21MI）。
实机只有少数页有（诊断页 448.2、成员页 5、钥匙页 13），多数是 14-16pt 平铺。
