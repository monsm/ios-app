
# §14 明令禁止 —— 25 条逐条结论

> 规范原话：**「命中即返工。」**
>
> 这份表是 2026-10-23 补的。此前我一直在按 §15 的 72 项数，**把 §14 这 25 条忘了** ——
> 于是说过「静态能判的已经判完了」，那句话是错的。

| # | 禁止项 | 结论 | 依据 |
|---|---|---|---|
| 1 | 应用体用白卡 | ✅ | 全仓 0 处 `.fill(.white)` / `background(.white)` 的卡片底。应用体卡片一律 `XPanel` → `XPalette.surface`(#1C1C1E)。 |
| 2 | 展示壳用深卡 + 浅字 | N/A | 本 App 没有展示壳（营销轮播）。 |
| 3 | `#0A0A0A`/`#111` 当页面底 | ✅ | 全仓 0 处。所有页面用 `XPalette.canvas`(#000000)，`contrast.js` 的「规范值锁定」钉住这个值。 |
| 4 | 给应用体卡片加投影 | ✅ | `.shadow(` 全仓 0 处（历史 7 处已清）。亮起来用辉光 radial，不用投影。 |
| 5 | 卡片圆角 < 20pt | ✅ | `XRadius.card = 24`、`XRadius.cardLg = 34`。机检出 21 处 radius 1–5 的形状，逐个看过**都是进度内条 / 色点 / 迷你条**，不是卡片。 |
| 6 | 内容层用毛玻璃 | ✅ **修** | 抓到一处：`SecurityCenterView.frostedPlate` 用 `.ultraThinMaterial` 盖 OTP。既违反分层，又没达成目的（该材质故意透背景，秘密可能被读出）。改实底 `surfaceAlt`。判据已加。 |
| 7 | 一屏两张渐变卡 | ⚠️ 判不了 | 需要渲染。本仓只有门厅一张 `XPanel(kind: .hero)`，静态看是一张；同屏可见性要在设备上确认。 |
| 8 | 玻璃上叠玻璃 | ✅ | `XGlassSurface` 是玻璃唯一实现，全仓只在 `XGlassTabBar`（功能层）用。内容层 0 处（#6 的判据同时覆盖这条）。 |
| 9 | 纯色（非渐变）描边画环 | ✅ **修过** | `FirmwarePage` 的大环曾是 `.stroke(XPalette.hairline, lineWidth: 14)` 纯色，已改渐变。机检：环形 stroke 无纯色。 |
| 10 | 一屏超过 3 种强调色 | ⚠️ 判不了 | 同 D2 —— 按文件统计不成立（一文件多页面），按同屏可见性需渲染。 |
| 11 | 11pt 以下字号 | ✅ **修** | 抓到四处：环内文字下限 `max(8,…)` / `max(9,…)`，104pt 环里实际渲染 9pt。一律提到 11。判据已加。 |
| 12 | 30% 白承载信息 | ✅ | `contrast.js` 40 条断言 + 规范值锁定；承载信息的文字最低 4.5:1，非文本 3:1。30% 白(#4D4D4D) 在任何底上都不达 4.5，全仓无此用法。 |
| 13 | 大环超过 1 个 | ✅ | 门厅 1 个 220pt（全屏唯一 ≥200pt 的主体）。开锁环与指纹环是同一族不同屏。`XSkeleton` 里的圆环不计数（它是占位）。 |
| 14 | Tab 选中用深色胶囊 | ✅ | `XSegmented` 与 `XGlassTabBar` 的选中块都是 `rgba(255,255,255,0.18)` **更亮**的微光胶囊，不是深色。 |
| 15 | 胶囊「标题白粗 + 值灰小」 | ✅ | `XStatChip`：标签在上（`textSub` 14 Regular）、值在下（`text` 14 Semibold）—— 主次正确。 |
| 16 | 卡片「图在上、文字在下」 | N/A | 本仓没有图文卡（§7.5 MediaCard 无消费者）。 |
| 17 | 图表画实线坐标轴 | ✅ | 唯一使用 SwiftUI `Chart` 的位置（`StatsPage` 近 14 天趋势）带 `.chartXAxis(.hidden)` + `.chartYAxis(.hidden)`。分时柱图是手绘发丝线 + 虚线网格。 |
| 18 | emoji 当图标 | ✅ | 全仓 emoji 扫描 2 处命中，都是 `✓`（U+2713）作为**文案里的对勾字符**，不是 emoji 图标。图标一律 SF Symbols（`iconmap --strict` 在跑）。 |
| 19 | 轮播加页码点 | N/A | 没有轮播。 |
| 20 | 弹跳动画 | ✅ | `motionlock` 把 §11.1 的六条曲线逐参数锁死，且禁止 `timingCurve` / `cubicBezier` / `custom`。过冲曲线在 token 层就不存在。 |
| 21 | 大环线宽 < 30pt | ✅ | `DSRing.stroke(forDiameter:)` 绑定直径与线宽，220pt → 30pt；`DSRing.minStrokeLarge = 30`。注释写明「改直径必须重算，否则环会变细」。 |
| 22 | 分段控件加下划线指示条 | ✅ | `XSegmented` 只有胶囊选中块，无下划线；全仓 0 处 `.underline`。 |
| 23 | 玻璃写死颜色、只测一种背景 | ⚠️ 判不了 | 「不写死颜色」已保证（靠 Material 吸背景 + 8% 白提亮，`XGlassSurface` 注释写明）。**但「亮/黑两种背景都要验」需要真机** —— 这正是 G1。 |
| 24 | Sports 用单层绿 | N/A | 没有 Sports 页。 |
| 25 | 关闭按钮做成 44pt 实心大圆 | ✅ | 全仓 0 处 44×44 的 xmark 实心圆。关闭按钮按 §7.0.4 走 36 视觉 / 44 命中。 |

## 汇总

| 结论 | 数 | 说明 |
|---|---|---|
| ✅ 合规 | 18 | 其中 3 条是**本轮修出来的**（#6 / #9 / #11）|
| ⚠️ 判不了 | 3 | #7 渐变卡张数 / #10 同屏色数 / #23 玻璃双背景 —— 都要渲染或真机 |
| N/A | 4 | #2 展示壳 / #16 图文卡 / #19 轮播 / #24 Sports —— 本 App 没有对应形态 |
