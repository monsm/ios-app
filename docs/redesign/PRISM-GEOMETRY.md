## 四、缺失的 z 平移

### 数学上应该有

三棱柱内切圆半径 A = 面宽 × 0.2887 = 393 × 0.9 × 0.2887 ≈ 102.1pt。

面 θ 的中心应在 `(A·sinθ, 0, A·cosθ)`：

| 面 | θ | sinθ | cosθ | 应有 x | 应有 z |
|---|---|---|---|---|---|
| b | 0° | 0.000 | 1.000 | 0 | **+102** |
| d | 120° | 0.866 | -0.500 | +88 | **-51** |
| f | 240° | -0.866 | -0.500 | -88 | **-51** |

### 实际实现

```swift
.offset(x: sin(rad) * prismApothem, y: 0)   // 只有 x
```

三个面全在 z=0 平面。

### 后果

| 场景 | 影响 |
|---|---|
| 静止时 | 看不出问题（当前面 z=1，就在正前方） |
| 转动时 | 本该「一前一后」的两个面变成「左右并排」→ 三张卡片横排滑动 |
| 淡入淡出 | **仍然正确**（由 faceVisibility 独立计算） |

**结论**：缺的是「前后纵深感」，不是「完全看不出是棱柱」。

## 五、SwiftUI 的三条死路（逐一确认）

| API | 为什么不行 |
|---|---|
| `.offset(x:y:)` | 没有 z 参数 |
| `.transformEffect()` | 收 `CGAffineTransform`（2D 矩阵） |
| `.projectionEffect()` | 只取 `CATransform3D` 的 3×3 部分，而平移在 4×4 的第四列 |

### 唯一可能的解法

`rotation3DEffect` 的 `anchorZ:` —— 旋转轴在 z 上的位置。
当 angle=0 时，视图跟着 anchorZ 沿 z 平移。

**但全仓 6 处 `rotation3DEffect` 都没用过这个参数。**

按既定纪律，已在 `RealityAPIProbe.swift` 加区块 6 验证签名：

```swift
Text("probe").rotation3DEffect(
    .degrees(0),
    axis: (x: 0, y: 1, z: 0),
    anchor: .center,
    anchorZ: 12.0,          // ← 待验证的标签名
    perspective: 0)
```

### 如果 anchorZ 不存在

退路：每面按自己的 z 分量施加不同 scale（正对 1.0 / 背对 0.85），
用已知的 `scaleEffect` 近似「远一点」。不是真 3D，但比现在好。

## 六、本轮修过的两个问题

### 1. reduceMotion 理解错了

用户原话「减弱动态不动三棱柱」。

我第一版做成「降级为交叉淡入」——三棱柱消失，且淡入本身也是动画。

**正确做法**：三棱柱照常渲染，只把
`containerAngle`（不随 drag/turn）、`breathScale`（恒 1）、
`step()`（直接跳面）、拖拽回弹（直接归零）全部去掉动画。

验证：reduceMotion 下三面缩放全部 1.0000，当前面完全可见。

### 2. F 域玻璃形状不一致

`axGlass(19)` 画的是圆角矩形（19 < 46/2），但选中态是 `Capsule()`，
且注释写着「复用 axGlass(.capsule)」。已改为 `axGlassCapsule()`。
