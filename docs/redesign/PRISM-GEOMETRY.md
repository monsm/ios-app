## 四、z 方向分布（已修复）

### 上一版文档的错误

我在第一版里写"只做 x 偏移，三面挤在 z=0 平面"——**这个描述不准确**。

实际上 `.offset(x:)` 经容器旋转**确实会产生 z 分量**。
真正的错误是 **x 偏移的量本身不对**。

### 真正的问题：三面不在同一个圆上

原本 `prismFace` 是：

```swift
.rotation3DEffect(.degrees(theta), axis: (0,1,0), anchor: .center, perspective: 0)
.offset(x: sin(theta) * apothem, y: 0)     // 只有 x
```

复算三个面经容器旋转后的实际位置（A = 102.1pt）：

| 选中面 | 面 | x | z | **半径** |
|---|---|---|---|---|
| b | b | 0 | 0 | **0**（在圆心） |
| b | d | +88 | 0 | 88 |
| b | f | −88 | 0 | 88 |
| d | b | 0 | 0 | **0** |
| d | d | −44 | +77 | 88 |
| d | f | +44 | −77 | 88 |

**三个面不在同一个圆上**：一个在圆心、两个在半径 88。
偏差 51–102pt。

### 修法：`anchorZ = -A`

```swift
.rotation3DEffect(.degrees(theta), axis: (x:0, y:1, z:0),
                  anchor: .center,
                  anchorZ: -prismApothem,
                  perspective: 0)
// 删掉 .offset(x:)
```

原理：让视图绕「中心后方 A 处」的轴旋转 θ。
视图中心相对轴是 (0, 0, A)，转 θ 后自然落在 (A·sinθ, 0, A·cosθ) ——
**正是棱柱上该在的位置**。

x 和 z 由旋转同时产生，不需要手写 offset。

### 修复后验证

| 选中面 | 三面位置 | 半径 |
|---|---|---|
| b | b(0,+102) d(+88,−51) f(−88,−51) | 全 102.1 ✓ |
| d | d(0,+102) f(+88,−51) b(−88,−51) | 全 102.1 ✓ |
| f | f(0,+102) d(−88,−51) b(+88,−51) | 全 102.1 ✓ |

- 三面半径全部 102.1pt ✓
- 选中面 z 最靠前（+102）✓
- 前后纵深差 153pt ✓

## 五、SwiftUI 的三条死路（逐一确认）

| API | 为什么不行 |
|---|---|
| `.offset(x:y:)` | 没有 z 参数 |
| `.transformEffect()` | 收 `CGAffineTransform`（2D 矩阵） |
| `.projectionEffect()` | 只取 `CATransform3D` 的 3×3 部分，而平移在 4×4 的第四列 |

### 唯一可能的解法

`rotation3DEffect` 的 `anchorZ:` —— 旋转轴在 z 上的位置。
当 angle=0 时，视图跟着 anchorZ 沿 z 平移。

**但全仓 6 处 `rotation3DEffect` 都没用过这个参数。**

按既定纪律，已在 `RealityAPIProbe.swift` 加区块 6 验证签名：

```swift
Text("probe").rotation3DEffect(
    .degrees(0),
    axis: (x: 0, y: 1, z: 0),
    anchor: .center,
    anchorZ: 12.0,          // ← 待验证的标签名
    perspective: 0)
```

### 如果 anchorZ 不存在

退路：每面按自己的 z 分量施加不同 scale（正对 1.0 / 背对 0.85），
用已知的 `scaleEffect` 近似「远一点」。不是真 3D，但比现在好。

## 六、本轮修过的两个问题

### 1. reduceMotion 理解错了

用户原话「减弱动态不动三棱柱」。

我第一版做成「降级为交叉淡入」——三棱柱消失，且淡入本身也是动画。

**正确做法**：三棱柱照常渲染，只把
`containerAngle`（不随 drag/turn）、`breathScale`（恒 1）、
`step()`（直接跳面）、拖拽回弹（直接归零）全部去掉动画。

验证：reduceMotion 下三面缩放全部 1.0000，当前面完全可见。

### 2. F 域玻璃形状不一致

`axGlass(19)` 画的是圆角矩形（19 < 46/2），但选中态是 `Capsule()`，
且注释写着「复用 axGlass(.capsule)」。已改为 `axGlassCapsule()`。
