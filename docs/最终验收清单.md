## 真机验证步骤

### A. 手动开锁
1. 进设备页，**等 2 秒**（预热 + 令牌预取）
2. 按住圆盘 1.2 秒 → 松手
3. 预期：**几乎立即开锁**
4. 遥测看 `开锁耗时: 凭证构建 Xms · 下发+rc Yms`（凭证 < 5ms / 下发 ≈ 100ms）

### B. 自动开锁
1. 设置 → 打开「走近自动开门」
2. 走到门口（1 米内），手机在手上、App 前台
3. 预期：**0.5 秒内**自动开锁
4. 若不开 → 看审计拒因（`F3 信号未达线` → 去标定；`F6 锁态` → 两方向都修了）

### C. 距离标定
**iOS**：设置 → 靠近自动开锁 → 「标定距离基准（可选）」
**Android**：设置 → 靠近自动开锁 → 「距离基准（可选）」→「标定」
站到目标位置 → 开始采样 20 秒 → 采够 5 个 → 保存

### D. 双开验证（第 52-53 轮）
1. 站门口触发一次自动开锁
2. **立刻杀掉 App**
3. 重开 App，仍站门口
4. 预期：**6 秒内不会立刻再开**（冷却已持久化）

### E. 并发验证（第 63 轮）
1. 站门口触发自动开锁
2. 在自动开锁在途时**点一下圆盘**
3. 预期：提示「自动开锁进行中，请稍候」并拒绝手动（**不会发第二帧 04**）

### F. 退后台验证（第 65 轮）
1. 站门口，等自动判定通过（开始建连）
2. **立刻退到后台**（锁屏）
3. 预期：**不会开门**（判定已作废）
