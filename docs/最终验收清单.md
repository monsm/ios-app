### 延迟预算

| 场景 | 优化前 | 现在 |
|---|---|---|

## 真机验证步骤

### A. 手动开锁（验证 1 次往返）

1. 进设备页，**等 2 秒**（预热 + 令牌预取）
2. 手指**按住**圆盘 1.2 秒 → 松手
3. 预期：**几乎立即开锁**
4. 设置 → 诊断 → 蓝牙遥测，找 `开锁耗时: 凭证构建 Xms · 下发+rc Yms`
   - 凭证构建 < 5ms（本地）
   - 下发 ≈ 100ms（一次往返）

### B. 自动开锁（验证 F6 死门已修）

1. 设置 → 打开「走近自动开门」
2. 走到门口（约 1 米内），**手机拿在手上、App 在前台**
3. 预期：**0.5 秒内**自动开锁 + toast「自动开锁成功」
4. 若不开 → 设置 → 诊断 → 自动开锁审计看拒因：
   - `F3 信号未达武装线` → **去做标定**（见 C）
   - `F1 面容未确认` → 严格档（默认标准档不弹窗）
   - `F6 锁态未知或忙` → **不应再出现**（已修）

### C. 距离标定（两平台新功能）

**iOS**：设置 → 靠近自动开锁 → 「标定距离基准（可选）」
**Android**：设置 → 靠近自动开锁 → 「距离基准（可选）」→「标定」

1. 站到**平时想让它自动开锁的位置**
2. 点「开始采样」，别动，采 20 秒
3. 采够 5 个样本后「保存」
4. 预期：显示「距离基准：N dBm（已标定）」

### D. Android 端

同上 A/B/C —— Android 现在与 iOS 逻辑完全对等。
