## 真机验证步骤

### A. 手动开锁
1. 打开 App，进设备页（等 2 秒让预热完成）
2. 手指**按住**圆盘 1.2 秒 → 松手
3. 预期：**几乎立即开锁**（建连已在按压期间完成，令牌已预取）
4. 设置 → 诊断 → 蓝牙遥测，找 `开锁耗时: 凭证构建 Xms · 下发+rc Yms`
   - 凭证构建应 < 5ms（本地）
   - 下发应 ≈ 100ms（一次往返）

### B. 自动开锁
1. 设置 → 打开「靠近自动开锁」
2. 走到门口（约 1 米内），**手机拿在手上、App 在前台**
3. 预期：**0.5 秒内**自动开锁 + toast「自动开锁成功 — 锁名」
4. 若不开：设置 → 诊断 → 自动开锁审计，看拒因是哪道门
   - `F3 信号未达武装线` → 阈值问题（需标定）
   - `F1 面容未确认` → 严格档（默认标准档不弹窗）
   - `F6 锁态未知或忙` → **不应再出现**（第 11 轮已修）
