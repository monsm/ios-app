## 三、可执行的升级方案（第二步：HTML → 参考图）

### 升级 A：卡片玻璃感（P1+P2）—— 共性问题，批量改 tokens.css

```css
/* 现在 */
.card { background: #1C1C1E; }
/* 改为（对齐参考图实测 R35G34B39，保留背景色相）*/
.card { background: rgba(255,255,255,.045); backdrop-filter: blur(20px); }
```

数学验证：纯黑 #000 上叠 4.5% 白 = R11.5 → 仍不够 35。
需叠 **13.7% 白** 才能到 R35。但那会让卡片发灰。
**更接近参考图的做法**：卡片底用 `rgba(255,255,255,.055)` + `backdrop-filter: blur(20px) saturate(1.4)`，
让背景的微弱冷光被模糊放大后透上来 —— 这正是参考图 R35G34B39 的成因（不是单纯加白）。

### 升级 B：卡片边距 14 → 26pt（P3）—— 共性问题，批量改 gutter

```css
/* 现在 */ :root { --gutter: 14px; }
/* 参考图实测 80px/1206 ≈ 6.6% ≈ 26pt */
:root { --gutter: 22px; }   /* 取 22-26 之间的保守值，避免小屏太挤 */
```

### 升级 C：彩色环饱和度（P5）—— 逐页检查，不批量

参考图的环用**系统色满饱和**（#FF3B30 / #30D158 / #64D2FF / #0A84FF）。
当前 HTML 多数环用线性渐变（#4A9E96→#0A84FF），**中段偏灰**。
改法：环改用**单一系统色**，或渐变两端都用满饱和色。

### 升级 D：图 6 双列卡片 —— 逐页补，不批量

参考图 5 的「Step Count / Step Distance」和「Sessions / Awards」都是**并排两张卡**。
HTML 里只有 03-devices 用了双列。其余仪表页（门厅·成员·诊断）可补。
