# DECISION-NEEDED — 26 项 ❌ 判定决策单

> 来源：FEATURE-TRIAGE.md 全部 26 条 ❌；名称出自 IDEA-BANK.md；替代建议摘自各 part「❌ 项清单与替代建议」节。
> 「建议决策」=「替代」（降级实现或挪落点后仍有实际价值）或「跳过」（原意无法承载、替代无实际内容）。请逐项拍板：同意 / 改判 / 补充。

## 根因概览

- **协议缺口（12 项，依据 CAPABILITY.md §5）**：锁端协议硬性不存在对应字段、命令或日志类型。典型例子：胁迫告警类型整个缺失（CAPABILITY §3 日志类型表无胁迫项），导致 596/607/725/744 四条胁迫类创意成批作废；涟漪结界（1009）因协议根本没有"上锁"命令与状态位而无真实触发点。
- **平台缺口（14 项，依据 CONSTRAINTS.md）**：免费开发者账号 App Groups 禁用，Widget / 控制中心控件 / StandBy 全部读不到 App 的 SQLite 与设置，只能做拉起 App 的哑按钮。典型例子：Part 4 的 924–935 区段 Widget 类创意全军覆没；938/940/944 还叠加"上锁状态位协议本就没有"的双重缺口。
