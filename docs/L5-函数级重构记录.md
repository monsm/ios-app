## 四、拆函数时踩的 5 个坑

1. **`@ViewBuilder` 是函数级的，不是语句级的。** 把 `Section` 里的 `header:`/`footer:` 块抽成函数时，如果 body 以 `if let` 起头（多分支不同类型），必须给新函数补 `@ViewBuilder`；否则报 "opaque return type"。
2. **参数必须显式带走。** `applyFilter` 里 `p`/`f`/`now`/`compactRow` 都是局部 `let`；抽 `credRowContent` 时必须作为参数传进去，不能指望闭包捕获。
3. **`guard` 替换 `if` 时要连括号一起改。** 把 `if let pend = ... { ... }` 改成 `guard ... else { return nil }` 时，原 `if` 的闭合 `}` 会多出来 —— `swiftcheck` 能立刻抓到 `depth=-1`。
4. **嵌套函数提成方法后，闭包里要补 `self.`。** `collector = { f in ... }` 里原本调用的是局部嵌套函数（不需要 `self`），提成方法后必须写 `self.press(of:)` / `self.isPress(f)`。这是 `fpStart` 那轮 CI 失败的根因。
5. **插入点必须在同一个类型内。** 不能假设「文件最后一个 `}`」就是宿主类型的闭合；一个文件可以有多个顶层类型。
