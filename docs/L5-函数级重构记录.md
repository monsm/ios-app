## 四、观察：拆函数时踩的 3 个坑

1. **`@ViewBuilder` 是函数级的，不是语句级的。** 把 `Section` 里的 `header:` 块抽成函数时，如果 body 以 `if let` 起头（多分支不同类型），必须给新函数补 `@ViewBuilder`；否则报 "opaque return type"。
2. **参数必须显式带走。** `applyFilter` 里 `p` / `f` / `now` / `compactRow` 都是局部 `let`；抽 `credRowContent` 时必须把它们作为参数传进去，不能指望闭包捕获。
3. **`guard` 替换 `if` 时要连括号一起改。** 把 `if let pend = ... { ... }` 改成 `guard let pend = ... else { return nil }` 时，原 `if` 的闭合 `}` 会多出来 —— 静态括号检查（`swiftcheck`）能立刻抓到 `depth=-1`。
