# DAYLIGHT · 设计语言

> 品牌：**阈 / Threshold** —— 门槛、门限。一个家，和它的边界。
> 视觉母题：**日光穿过玻璃**。不是"把门画在屏幕上"，也不是"仪表盘"。

---

## 1. 概念

门锁是**边界**。人每天跨过它：出去、回来。
日光每天也跨过它：从窗、从门缝、从楼道的一侧到另一侧。

所以这个 App 的空间只有三层：

| 层 | 是什么 | 在界面上 |
|---|---|---|
| **室外** | 会变化的自然光 | `DaylightField`：整页的暖日光场，极慢漂移 |
| **边界** | 一块有厚度的玻璃窗 | `DaylightPane`：主页的日光窗；下沿就是门槛 |
| **室内** | 安静、可读、可操作 | 陶土纸底上的读数、托盘、台账 |

**唯一的主角**：主页那扇窗 + 骑在窗沿上的**玻璃镜头**。
镜头环走的是真实命令链（连接 → 下发 → 等回执 → 成功/断点），不是假动画。

## 2. 颜色

只有三个家族：**陶土纸（无彩暖灰）**、**黄铜（唯一强调色）**、**语义色**。

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `canvas` | `#F3F0E9` | `#0D0F12` | 页面底 |
| `canvasTop` | `#E7EEF3` | `#121820` | 顶部冷日光 |
| `ink` | `#14161A` | `#F3F1EC` | 主文字 |
| `ink2` | `#555A61` | `#A8ACB2` | 次级文字 |
| `ink3` | `#666B72` | `#83888F` | 说明文字（4.5:1 起） |
| `ink4` | `#9AA0A7` | `#565C64` | 装饰点 / 分隔 |
| `brass` | `#7C5A31` | `#D8B47F` | 强调、动作、品牌 |
| `brassBright` | `#C79E63` | `#E9CEA3` | 光、渐变、装饰（不用于小字） |
| `danger` | `#A8452E` | `#E2735C` | 危险 / 异常 |
| `ok` | `#3F7250` | `#7FB08C` | 可证明 / 成功 |
| `onAccent` | `#FFFFFF` | `#0D0F12` | 黄铜 / 危险实底上的文字与图标 |
| `glass` | `#FFFFFFB8` | `#1B2027A6` | 玻璃面 |
| `atmoWarm/Cool` | 暖 / 冷光 | 暗暖 / 暗冷 | 只有日光场用 |

**可用性**：这套材质是 **iOS 26** 的原生 Liquid Glass（`glassEffect`）——
本 App 的**基线**就是 iOS 26（CI 的 Xcode 27.1 工具链不接受更低的部署目标）。
iOS 26 的能力直接用，不写分支；需要分支的只有 **iOS 27** 的新能力
（轻扫容器、基于数据的弹窗、工具栏溢出菜单），它们在 iOS 26 上有等价降级。
分支全部收在 `App/Design/Modern.swift` 一处，页面里不写 availability 判断。
逐项对照见 [IOS26-27-UPGRADE.md](IOS26-27-UPGRADE.md)。

**纪律**：
1. 同屏只有一个强调色（黄铜）。状态色只在真实状态出现。
2. 玻璃只做"层"：浮层、控件、内容卡片三档；不用玻璃去装饰纯文本段落。
3. 文字色对比度全部 ≥ 4.5:1（`Gates/contrast.js` 现场计算，明暗各一套）。
   实底上的文字用 `onAccent`（浅色白 / 深色近黑），不写死 `.white` ——
   深色模式的黄铜是亮色，白字压上去只有 1.9:1。
4. `ink4` 只用于装饰点、分隔和拖拽把手（2.3:1），**不承载文字或状态图标**；
   要读的说明文字最低用 `ink3`（4.7:1 起）。

**一套玻璃，三种角色**：

- 材质参数只有一份：`LiquidGlass.swift` 的 `GlassMetrics`（圆角、描边、顶缘高光、黄铜染色）。
  页面与组件里不再出现 `.ultraThinMaterial` 手工叠层（材质统一由 `LiquidGlass.swift` 收口）或材质圆角字面量。
- 浮层（Tab 栏、工具托盘、解锁镜头、临时提示、圆形浮钮）与控件（次要按钮、输入框、
  分段控件、选项胶囊、键盘键）都用 iOS 26+ 的原生 `.glassEffect`，带黄铜染色；
  可点的加 `.interactive()`，相邻成组的（键盘）套 `GlassEffectContainer`。
  （本仓封装成 `GlassGroup`）—— 玻璃采样的是**真实内容**，不在同一个容器里的
  两片相邻玻璃会各折各的，接缝会花。
- 镜头的玻璃是**可变形**的：开锁成功时它真的「推开」成一圈光
  （`glassEffectID` + `glassEffectTransition(.matchedGeometry)`），不是画一个假缩放。
- 内容卡片（`GlassSurface`）同样走原生玻璃，但**不染色**：一页里可能同时出现几张卡，
  染色叠染色会让整页泛黄。
- 打开「减少透明度」或「增强对比度」时，同一个入口退化为不透明面板 + 实边（增强对比度
  时描边加倍），不让可读性依赖透明材质；深色模式下顶缘高光从 30% 收到 16%。
- 主行动按钮（`PrimaryButton`）保持黄铜实底 —— 它是页面唯一的强调动作，不参与折射。

## 3. 字

三种字体各司其职，对比拉到最大：

| 角色 | 字体 | 用途 |
|---|---|---|
| **展示** | 衬线（Songti SC） | 每屏一句大标题；只说一件事 |
| **界面** | SF Pro / PingFang | 标题、正文、按钮 |
| **数据** | SF Mono | 时间、读数、指令码、Kicker |

- 大标题 34–46pt，字距 -0.8；正文 15–16pt；说明 11.5–13pt。
- 所有字号都走 `TypeStyle`，内部用 `@ScaledMetric` / `UIFontMetrics` 跟随动态字体。
- 中文标题最高 semibold（苹方没有 Bold）。

## 5. 组件语法

### 5.1 窗（DaylightPane）
- 高 250–396；内部只放三样：Kicker、一句衬线、一句说明。
- 下沿是一条 `0.5pt` 的门槛线。
- 光：冷白左上 + 暖金右上 + 一道斜光；都是 `blur` 过的圆，不是图片。

### 5.2 镜头（UnlockLens）
- 116pt 玻璃圆，中心 44pt 黄铜盘 + 锁孔。
- 环：`trim(from:0,to:progress)`，3pt，从 -90° 起。
- 相位：`idle → reaching(0.26) → sending(0.62) → waiting(0.86) → opened(1.0)`；失败停住并变朱红。
- 按下缩到 0.965；触觉反馈由 `sensoryFeedback` 给。

### 5.3 读数（ReadingRow）
- 三列，竖线分隔；标签是 9.5pt Mono 大写，值是 19pt 等宽数字，单位是 11pt。
- 只显示真的读到的值；读不到就是 `—`，不猜。

### 5.4 章节（SectionHead）
- `01 — 最近 ——————— 全部`：编号黄铜、标题 13pt、细线、右侧计数。
- 编号是页面内的顺序，不是装饰。

### 5.5 行（ContentRow）
- 图标砖 40 + 标题 + 副标题 + 右侧值/徽标 + chevron。
- 分隔线只出现在行之间，`0.5pt`，左边缩进到文字起点。

### 5.6 工具托盘（ToolTray）
- 一块玻璃，四格，竖线分隔；图标黄铜、标签 11.5pt。
- 只放用户最常用的四个动作；其余在「通行 / 设置」里。

### 5.7 Tab bar
- 60pt 高的浮动玻璃板，三个 Tab。
- 选中：图标黄铜 + 文字 ink + 底部 3pt 圆点。

### 5.8 空态（EmptyNote）
- 一句衬线 + 一句说明 + 一个文字动作。
- 永远给出下一步，不写「暂无数据」。

## 6. 信息架构

```
Shell（3 Tab + 底栏第 4 个按钮「设置」）
 ├─ 今日   TodayScreen
 │    ├─ 日光窗 + 镜头（开锁）
 │    ├─ 读数 / 工具托盘 / 最近
 │    └─ 右上角头像（身份标记，不可点）
 ├─ 通行   AccessScreen
 │    ├─ 凭证（临期 / 全部 / 详情 / 新建）
 │    ├─ 成员（名册 / 档案 / 新建）
 │    └─ 手机钥匙（签发 / 吊销 / 二维码）
 ├─ 记录   LogScreen
 │    ├─ 日光带（24 小时）
 │    ├─ 按天分组的时间线
 │    ├─ 详情（备注 / 处置 / 同一天）
 │    └─ 洞察
 └─ 设置（独立栈，底栏第 4 个按钮 → sheet）
      ├─ 我的家：我的锁 / 安全 / 成员入口
      ├─ 设备与工具：门锁设置 / 自动开门 / 钥匙串与网关 / 固件 / 诊断 / 配对
      └─ 数据：备份与恢复 / 外观 / 关于
```

**为什么是 3 个 Tab + 1 个设置按钮**：这个 App 每天的最高频动作只有一个（开门）。把「门」做成一个 Tab 等于把"开门"降级成"一个页面"；把「今日」做成主场、把「通行」和「记录」做成它的两个侧面，结构才和真实使用一致。设置不是目的地，是工具箱 —— 所以它不占 Tab、不参与选中态，而是底栏第 4 个按钮，点开独立栈的 sheet。它和三个 Tab 同一排、同一尺寸，永远在拇指够得到的地方，不依赖页面头部的任何元素。

## 8. 动效

- UI：`T.M.snap`（0.28 / 0.9）与 `T.M.settle`（0.45 / 0.86）两个弹簧。
- 日光场：42 秒的 `repeatForever(autoreverses:)` 漂移，只改位置，不改透明度。
- 开锁：镜头环随相位走；成功时停 0.9 秒；失败停在断点。
- 减少动态：日光场不动；所有弹簧仍在（它们是状态反馈，不是装饰）。

---

## 9. 刻意不做的东西

- 没有渐变标题、没有三张图标卡并排、没有"数据大盘"。
- 没有把门/锁/房子画成插图。
- 没有第二个强调色，没有荧光色。
- 没有在纯文本段落上铺玻璃；卡片用不染色的玻璃，不喧宾夺主。
- 没有用低对比的浅灰当"高级感"。
- 没有假进度、假成功：镜头只在锁真的回执后才到 1.0。

---

## 10. 诚实的边界

- DesignLab 是 HTML 镜像，只能验版式 / 层级 / 间距 / 色彩 / 信息密度；**手感、真实材质折射、PingFang 中文度量**要真机。
- 深色模式是为夜间楼道调的，不是把浅色反相。
- 大字号的极端值（AX5）只保证布局不裁字的方向正确，最终要看真机。
